Release notes
v0.82.1 - 2026-09-15
Added
  • An integration setup no longer has a maximum duration: the setup dialog keeps the session alive, so a driver may wait for the user as long as needed.
  • The device language is sent to the integration driver when a setup starts, so a driver can return its setup pages in the language of the remote.
  • A driver-provided error message is shown on the setup failure page instead of a generic error text.
  • While the remote runs on battery, the setup dialog shows how much time is left before the setup ends.
